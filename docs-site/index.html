SCENE 02 · REWRITE

不爽的剧情，当场改成你想要的

长按那段文字写想法 → AI 照着改 → 不满意还能一键回滚。

标注 → AI 改写 → 版本回滚

✍️ 指哪改哪，改砸了能反悔

长按任何一个段落写下你的不满——"这里节奏太慢，加一场雨夜追逐"。AI FAB 亮起红点，点开看它干活，改完顶部滑入横幅。每次改动都存历史版本，不喜欢随时还原。

  • 小修小补不惊动 AI：改错别字、调一句对话，精确替换，其他一字不动
  • 大改也行：续写烂尾、插入新章节、让反派洗白、把结局掰成开放式
  • 风格标签：赛博朋克 / 暗黑 / 轻松日常自由组合，每章套不同味儿
  • 版本历史：用户编辑 / AI 改写 / 手动快照，逐版预览与还原

💬 会用工具的写作助手

  • 全部本地：书、章节、角色、游戏存档全部存在手机本地，不依赖账号

SCENE 04 · PLAY

文字游戏：让 AI 给你当 GM

把书架上的小说变成互动文字冒险——AI 主持剧情，你做选择，骰子判命运。

旁白 → 台词 → 骰子 → 你的选择

🎲 打字机里跑出来的互动小说

AI 游戏主持人逐段旁白、让 NPC 开口，每回合递上 2–4 个选项——你可以点选项，也可以直接打字描述自己的行动。命运骰子真掷真算，结果连 GM 都不能改。

  • 改编自带的书：NPC 的性格、说话腔调都来自你书架那本书的角色卡
  • 打字机流式演出：旁白逐字蹦出，"幕后"按钮能看 GM 的思考过程
  • 回溯时间线：任何一步选择都能「回溯到这一步」重选，设定不丢
  • 自动配图：关键场景端侧生成插图，插进剧情流里
  • 离开页面剧情照跑：回来接着玩，存档永远在本地
